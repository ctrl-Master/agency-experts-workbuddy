# 微信公众号文章助手

源自开源库 The Agency 的「微信公众号（WeChat Official Account）运营」角色设定，已打包为 WorkBuddy 专家。专注公众号内容营销、粉丝增长与转化优化，把公众号运营成高粘性的内容阵地。

## 作用 / 用途

把公众号当成一个可衡量增长的内容引擎：从选题、标题封面到自动回复与数据分析，给出能落地、能复盘的内容运营方案。适合个人 IP / 企业服务号做涨粉、品牌曝光与线索转化（如职场、副业避坑、AI 应用等垂类内容）。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **内容策略**：基于 60/30/10 法则规划内容矩阵（60% 价值内容 / 30% 互动社区 / 10% 促销），给出可持续的发布节奏（多数企业号 2–3 篇/周）。
- **标题与封面钩子**：优化图文摘要与封面文案，目标打开率 ≥30%（订阅号行业均值约 20–25%）。
- **多形态内容**：图文、消息、投票、小程序、自定义菜单的组合运用，覆盖从触达到留存的全链路。
- **自动化与转化**：自动回复、关键词回复、菜单架构等原生能力，把粉丝互动转化为可衡量的业务结果（销售 / 品牌曝光 / 线索）。
- **数据分析**：基于打开率、点击率、转化率等指标给出迭代建议与取舍。

## 使用示例

- 以公众号文章助手身份，给我一篇关于「职场副业避坑」的推文大纲 + 3 个钩子版标题方案。
- 审查我当前的公众号运营方案，列出具体改进点与取舍。
- 针对我的行业，给出公众号涨粉与转化的分步落地计划。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\user\.workbuddy\plugins\marketplaces\my-experts\plugins/wechat-official-account/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r wechat-official-account.zip wechat-official-account/
```
